## 🚀 গিটহাব ও গিটহাব পেইজে প্রকাশের নির্দেশিকা (GitHub Pages Guide)

একাডেমির ওয়েবসাইটটি যেকোনো সময় খুব সহজে গিটহাবে আপলোড করে সম্পূর্ণ বিনামূল্যে লাইভ করা সম্ভব:

### ধাপ ১: গিটহাব রিপোজিটরি তৈরি
১. [github.com](https://github.com)-এ আপনার একাউন্টে লগইন করুন।
২. **New Repository** বাটনে ক্লিক করুন।
৩. রিপোজিটরির নাম দিন, যেমন: `al-muinul-quran-academy`।
৪. রিপোজিটরিটি **Public** রাখুন এবং Create Repository চাপুন।

### ধাপ ২: কোড আপলোড করুন
আপনার লোকাল কম্পিউটারে টার্মিনাল খুলে নিচের কমান্ডগুলো চালান:
```bash
git init
git add .
git commit -m "Initial commit for Al Muinul Quran Online Academy"
git branch -M main
git remote add origin https://github.com/<আপনার-ইউজারনেম>/al-muinul-quran-academy.git
git push -u origin main
```

### ধাপ ৩: গিটহাব পেইজ চালু করুন
১. আপনার রিপোজিটরির **Settings** ট্যাবে যান।
২. বাম পাশের মেনু থেকে **Pages** সিলেক্ট করুন।
৩. **Build and deployment** সেকশনে Source হিসেবে **GitHub Actions** নির্বাচন করুন।
৪. রিপোজিটরিতে আগে থেকেই `.github/workflows/deploy.yml` ফাইল দেওয়া আছে, তাই পুশ করার সাথে সাথে স্বয়ংক্রিয়ভাবে ওয়েবসাইট বিল্ড হয়ে লাইভ হয়ে যাবে!

## 📋 ভর্তি ফর্মের সাথে গুগল শিট যুক্ত করার উপায় (Google Sheets Webhook Setup)

শিক্ষার্থী যখন ওয়েবসাইটে ফর্ম পূরণ করবে, তখন সরাসরি একটি গুগল শিটে সব তথ্য জমা হওয়ার ব্যবস্থা:

১. একটি নতুন গুগল শিট (Google Sheet) খুলুন।
২. প্রথম সারিতে কলামগুলোর নাম লিখুন:
   `Submitted At | Student Name | Age | Country | Gender | Course | Medium | Class Time | Timezone | WhatsApp | Email | Application Type | Message`
3. শিটের **Extensions > Apps Script** মেনুতে যান।
4. নিচের কোডটি পেস্ট করে সেভ করুন:

```javascript
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    sheet.appendRow([
      data.submittedAt,
      data.studentName,
      data.age,
      data.country,
      data.gender,
      data.courseName,
      data.preferredLanguage,
      data.preferredClassTime,
      data.timezone,
      data.whatsappNumber,
      data.email,
      data.applicationType,
      data.additionalMessage
    ]);
    return ContentService.createTextOutput(JSON.stringify({"status": "success"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (error) {
    return ContentService.createTextOutput(JSON.stringify({"status": "error", "message": error.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
```

৫. ডান পাশের **Deploy > New deployment** বাটনে ক্লিক করুন।
৬. Select type: **Web app** সিলেক্ট করুন।
৭. Who has access: **Anyone** নির্বাচন করে Deploy করুন।
৮. প্রাপ্ত Web app URL-টি কপি করে রাখুন।
